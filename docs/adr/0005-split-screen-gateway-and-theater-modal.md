# 5. Split-Screen Gateway & Theater Modal UX

We decided to deliver a Split-Screen Gateway on initial visit coupled with an immersive Theater Modal for video showcase items:
- The Gateway visually contrasts the cinematic motion aesthetic with the structured data engineering aesthetic, inviting the user to choose their focus while allowing frictionless switching later via the persistent navigation Switcher.
- The Theater Modal replaces direct inline YouTube embeds with rich, dark-mode overlays that host high-definition video playback alongside production metadata (roles, tools, storyboards, timeline chapters), maximizing load performance and viewing immersion.

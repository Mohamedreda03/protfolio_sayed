# 1. Use Appwrite with Custom Admin Dashboard for Portfolio Data Management

We decided to use Appwrite as the backend service (Databases, Auth, Storage for imagery) coupled with an in-app Custom Admin Dashboard built into the Next.js application, rather than hardcoding data in JSON/Markdown or relying strictly on the third-party Appwrite Console. This empowers the owner to update all showcase items, metrics, skills, and bio information dynamically without redeploying code, while keeping the administrative interface tailored and seamless.

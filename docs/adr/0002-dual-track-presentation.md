# 2. Dual-Track Presentation Architecture

We decided to structure the portfolio around two primary Tracks (`Cinema Reel` and `Data Engine`) unified under a single site with an interactive Switcher, rather than building two disjointed portfolio websites or forcing them into a single generic grid. This preserves the owner's multi-disciplinary identity while delivering specialized visual aesthetics, layouts, and storytelling formats appropriate for both video production and distributed data engineering.

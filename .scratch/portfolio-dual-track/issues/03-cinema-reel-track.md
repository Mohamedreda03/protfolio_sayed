# 03: Cinema Reel Track & YouTube Theater Modal

**What to build:** An immersive video editing portfolio surface displaying video showcase items in a high-production poster grid with hover previews and category filters (Commercials, Documentaries, Motion Graphics). Clicking any project launches a cinematic Theater Modal featuring an embedded YouTube player, project backstory, role breakdown, and software stack.

**Blocked by:** 01: Dual-Track Foundation, Appwrite Service Layer & Switcher Shell

**Status:** ready-for-agent

- [x] Showcase Items grid tailored for video editing work with poster images, title, client, year, and software badges.
- [x] Cinematic Theater Modal component displaying embedded YouTube video in 16:9 responsive frame.
- [x] Project breakdown panel inside the modal highlighting role, challenge, color grade notes, and tools.
- [x] Keyboard accessibility (ESC to close, spacebar to pause/play, tab focus trapped).

# 02: Split-Screen Gateway Landing Experience

**What to build:** A split-screen hero gateway greeting visitors on their first arrival, allowing them to choose between entering the Cinema Reel experience or the Data Engine experience, with smooth transition animations and an option to explore the unified portfolio.

**Blocked by:** 01: Dual-Track Foundation, Appwrite Service Layer & Switcher Shell

**Status:** ready-for-agent

- [x] Split-screen gateway component with dual visual lanes (Cinematic Reel vs Data Engine).
- [x] Hover and selection animations that dynamically highlight the selected track.
- [x] Quick-action buttons to directly activate a track and scroll to showcase content.
- [x] Fluid responsive layout adapting gracefully to mobile viewports.

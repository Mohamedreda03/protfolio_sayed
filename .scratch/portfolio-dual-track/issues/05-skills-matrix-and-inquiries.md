# 05: Skills Matrix & Direct Inquiries Contact System

**What to build:** A cross-domain Skills Matrix allowing visitors to inspect expertise in both video post-production tools and distributed data technologies, along with an interactive Contact Me section that captures inquiries and saves them directly to Appwrite with graceful fallback handling.

**Blocked by:** 01: Dual-Track Foundation, Appwrite Service Layer & Switcher Shell

**Status:** ready-for-agent

- [x] Unified Skills Matrix component filterable by Track (Cinema vs Data).
- [x] Visual indicators of mastery, tools, frameworks, and cloud infrastructure.
- [x] Interactive contact form with validation, submission states, and toast notifications.
- [x] Integration with Appwrite inquiries collection with fallback logging when offline.
